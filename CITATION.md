# How to cite

If this work helps yours — whether you run an engine, build on a result, or reference the prime-power reduction frontier — a citation is the credit the licenses ask for. Here is exactly how.

The author should be cited as **Rafael Amichis Luengo**, or, where an abbreviated form is required, as **Amichis Luengo, R.**

## Plain citation

> Amichis Luengo, R. (2026). *The Hodge–Fermat Campaign: verifying the Integral Hodge Conjecture for high-dimensional Fermat varieties, and the prime-power reduction frontier.* https://github.com/tretoef-estrella/prime-power-frontier

## BibTeX

```bibtex
@software{amichisluengo2026hodgefermat,
  author  = {Amichis Luengo, Rafael},
  title   = {The Hodge--Fermat Campaign: verifying the Integral Hodge
             Conjecture for high-dimensional Fermat varieties, and the
             prime-power reduction frontier},
  year    = {2026},
  url     = {https://github.com/tretoef-estrella/prime-power-frontier},
  note    = {Computational verification via the Degtyarev--Shimada criterion}
}
```

## Citing a specific result

If you reference a single verdict or the Frontier specifically, name it directly — for example:

> The cell (6,6) was verified PRIMITIVE, the first composite-degree Fermat cell decided this way (Amichis Luengo, 2026), in the course of locating the prime-power reduction frontier.

GitHub also reads the [`CITATION.cff`](CITATION.cff) file in this repository, so a "Cite this repository" button appears on the repository page with these details ready to copy.
